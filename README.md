# quadra portfolio

Next.js 14 (App Router) + TypeScript + Tailwind CSS.

    npm install
    npm run dev

Open http://localhost:3000

## Edit your content
Everything (names, roles, bios, projects, reviews, FAQ, stats, contact) lives in `lib/data.ts`.
All numbers and quotes are placeholders. Replace them with real ones.
